Rip your DVDs straight into Plex.

Insert a disc, name it, and Plex Burner copies it into your media folder, then ejects it so the next one can go in. Runs in Docker on your own network.

Open the dashboard View on GitHub

How it works

1. Insert a discPlex Burner detects it and reads the title.
2. Name itThe title is pre-filled. Change it, or wait and it starts on its own.
3. Pick a folderChoose where it's saved, or create a new folder. Your choice is remembered.
4. CopyDVDs become a folder Plex plays directly. Data discs become an ISO.
5. EjectThe disc pops out when it's done, ready for the next one.

Install with Docker

git clone https://github.com/bhxuk/Plex_burner
cd Plex_burner
sh scripts/update.sh

Then open http://<server-ip>:9000. Set MEDIA_ROOT, EXTRA_ROOT and PB_HOST_DIR if your folders differ from the defaults in docker-compose.yml.

Updates

The dashboard checks GitHub for new commits. The Update now button pulls the latest code and rebuilds the container, and the changelog shows what changed.
